Python AI Learning Project
THis project helps you to start an AI learning Project Development. In this Project we will use basic python code and python enviroment.

Whats happening in this project?
- main.py --- wants to Ex.
- code/lesson_01_intro.py --- Python variables aur print() ka
  simple example hai.
- notebook/ --- Jupyter Notebook files rakhne ke liye folder.
- docs/ --- notes aur documentation rakhne ke liye folder.
- pyproject.toml --- project ka naam, Python version aur
  dependencies ki information.
- uv.lock --- uv ke zariye dependencies ke versions lock karne
  wali file.

Important Points
- Python 3.14 ya us se naya compatible version
- uv package manager (agar project ko uv ke saath chalana hai)
